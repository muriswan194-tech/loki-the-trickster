## Proposed compact asset kit

### Modular architecture

- Warm stone floor modules with two trim variants and controllable tiling.
- Straight wall, corner wall, low cover wall, arch bay and doorway.
- Column base/shaft/capital; stepped stair/ramp; raised landing.
- Balcony/bridge segment, railing and gate/bifrost frame.
- Palace roofline/spire silhouette for distance.
- Banner/pole and window recess as cheap dressing variants.

Each piece needs documented Unity-unit dimensions, pivot, snap increments, lightmap/UV density, material slots, collider policy and LOD policy. None of these values is supplied by the concept boards; choose one standard grid during implementation.

### Props and interaction tier

**Small jam set:** court bell (noise), two movable crates (movement/cover/noise), one planter or urn (cover/occlusion), one market table (visual anchor), one apple/sceptre/Tesseract optional pickup if retained. A fountain and a handful of banners can be decorative. Add only objects with known behavior and feedback; do not attempt every prop concept (climbable banner, carryable vase, pedestal puzzle, water/fire system) in the current jam scope.

Current JSON props include two bells, signal lamp, mirror, two movable crates, optional hidden sceptre/Tesseract and hearth. Preserve their IDs unless data/code is migrated together. Runtime-generated scenery has many additional decorative forms; the final pass should distinguish interactable colliders from scenery.

### Character assets

- Loki: original 3D mesh/rig, cloth/cape shape, green/gold materials, optional separate horn/hair pieces.
- Guard: one original mesh/rig/armor set, shield/staff silhouette and state cues.
- Deadpool cameo placeholder: original red/black non-injurious silhouette if allowed; cameo-only.
- No production-rigged character FBX is present in the listed art inventory. The current Loki/guard builds are procedural runtime assemblies.

### Materials, VFX and lighting

Stone (warm roughness), aged gold/bronze (moderate metalness, not mirror), painted wood, deep green cloth/leather, crimson cloth and emerald emissive. Reuse one emerald VFX family: short hand cue, local ring/spark and decoy shimmer. Keep the illusion silhouette readable and particles brief. Use directional warm sun, ambient cool fill, restrained fog and soft shadows; do not add a custom post-processing stack just for outlines.

### UI and audio

Keep main menu, objective/intro line, guard awareness, interaction prompt, ability controls and toast feedback consistent with the same gold/cream/green type hierarchy. Avoid the full mission-map/cooldown density in the UI concept. Audio needs are short: footsteps, bell/clatter, soft magic cue, guard alert/reaction, portal impact and concise comic stingers. No licensed movie music/voices.

## Asset acceptance checklist

- Correct scale and pivots; snaps to the documented grid.
- Silhouette reads from the gameplay camera, not only orthographic concept view.
- Material response matches warm stone / aged metal / cloth.
- Collider matches traversable/cover/useful shape and is not overcomplicated.
- Interactive state produces visible/audio feedback; decorative object never pretends to be usable.
- Source, license, attribution and import settings recorded for every non-project asset.
- No external network dependency at runtime.
